# Sheaf: PDF Reader

A PDF reader and editor for the Mac, by [CoBuild](https://thecobuild.pages.dev). Now in beta.

**Download:** [thecobuild.pages.dev/sheaf](https://thecobuild.pages.dev/sheaf/)

- Free to read, for good: open, search, outline, bookmarks, tabs, present and read aloud.
- Sheaf Pro adds editing the real text, annotating, signing, page tools, OCR and AI. Your first 14 days of Pro are free, then US$20 a year.
- Works offline. macOS 14 Sonoma or later.

The app is closed source. This repository only holds the release downloads; the website always serves the newest one.

First time opening it? See [the 3 quick steps](https://thecobuild.pages.dev/sheaf/install/). Found a bug? [Tell us](https://thecobuild.pages.dev/contact/).
